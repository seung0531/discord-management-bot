Discord 관리 봇

프로젝트 소개
Discord 서버 운영을 위해 개발한 커뮤니티 관리 봇 입니다.
Discord 서버 운영 과정에서 발생하는 신규 유저 인증 절차와 게임 파티 모집 과정을 자동화하기 위해 개발하였습니다. 운영자의 반복 작업을 줄이고 사용자들이 별도의 관리자 개입 없이 파티를 구성할 수 있도록 설계하였습니다.

주요 기능

1. 자동 인증 시스템
사용자가 지정된 인증 채널에 특정 키워드를 입력하면 인증 역할을 자동으로 부여하고 신규 유저 역할을 자동으로 제거하도록 구현하였습니다. 

2. 게임 모집 시스템
/모집 명령어를 통해 모집 생성 UI를 제공하고 게임, 모집 인원, 모집 시간을 설정하여 모집글을 자동으로 생성하도록 구현하였습니다. 

3. 실시간 참여 관리 시스템
버튼 기반 UI를 활용하여 참여, 나가기, 추방, 모집 종료 기능을 제공하였습니다.
참여자는 실시간으로 모집에 참여하거나 나갈 수 있으며, 모집글 작성자는 참여자를 관리하고 모집을 종료할 수 있도록 구현하였습니다.

4. 영구 데이터 저장
서버 재시작 시 모집 데이터가 초기화되는 문제를 해결하기 위해
JSON 파일 기반 영구 저장 구조를 구현하였습니다.
이를 통해 모집 상태 및 참여자 정보를 지속적으로 보존할 수 있도록 하였습니다. 

5. 서버 운영 자동화
systemd를 활용하여 봇 오류 발생 시 자동 재시작되도록 구성하였으며, Oracle Cloud 환경에서 장시간 안정적으로 운영할 수 있는 환경을 구축하였습니다. 

기술적으로 해결한 문제

- 문제1 Persistent View 적용 

문제: 봇 재시작 시 모집글의 버튼이 비활성화되어 사용자가 참여 기능을 사용할 수 없었습니다.

해결: discord.py의 Persistent View 기능을 적용하여 View 상태를 복구하도록 구현하였습니다.

결과: 서버 재시작 이후에도 기존 모집글의 버튼이 정상적으로 동작하도록 개선하였습니다.

- 문제2 모집 데이터 영속성 구현 

문제: 모집 데이터가 메모리에만 저장되어 있어 서버 재시작 시 모든 모집 정보와 참여자 정보가 초기화되는 문제가 있었습니다. 

해결: JSON 파일 기반 영구 저장 구조를 구현하여 모집 상태와 참여자 정보를 파일에 저장하고 복구할 수 있도록 개발하였습니다. 

결과: 서버 재시작 이후에도 기존 모집 데이터가 유지되어 사용자가 중단 없이 모집 기능을 이용할 수 있도록 개선하였습니다.

- 문제3 24시간 운영 환경 구축

문제: Oracle Cloud 무료 서버 환경에서 메모리 부족으로 인해 봇 프로세스가 종료되는 문제가 발생하였으며 장시간 안정적인 운영이 어려웠습니다.

해결: Swap 메모리를 확장하고 systemd 자동 재시작 정책을 적용하여 프로세스 종료 시 자동으로 복구되도록 구성하였습니다.

결과: 24시간 상시 운영이 가능한 환경을 구축하였으며 예기치 않은 오류 발생 시에도 서비스가 자동으로 복구되도록 개선하였습니다.

- 문제4 SSH 인증 및 배포 환경 구축

문제: Oracle Cloud 서버 배포 과정에서 SSH 인증 오류가 발생하여 원격 서버 접속 및 코드 배포가 불가능한 문제가 있었습니다.

해결: Ed25519 SSH 키를 재생성하고 authorized_keys를 재설정하여 인증 문제를 해결하였습니다. 또한 SSH 및 SCP 연결을 검증하여 안정적인 원격 배포 환경을 구축하였습니다.

결과: 원격 서버 접속이 정상적으로 가능해졌으며 코드 업로드 및 서버 배포 작업을 안정적으로 수행할 수 있는 환경을 구축하였습니다.

프로젝트 성과
- Oracle Cloud 서버에 실제 배포
- 24시간 상시 운영 환경 구축
- Persistent View 적용으로 재시작 후에도 버튼 기능 유지
- JSON 기반 데이터 영속성 구현
- 인증 및 파티 모집 프로세스 자동화
